# Libreta de Propinas

App web para repartidores: sacás una foto a la pantalla de pedidos ("Armar Viaje"), lee las direcciones y te las ordena según la propina promedio que deja cada una. También lleva el registro de cada propina.

- La lectura de la foto usa [Tesseract.js](https://github.com/naptha/tesseract.js) y corre en el celular: sin servidor, sin IA y sin costo.
- Las propinas se guardan en el navegador del celular. Usá "Guardar copia de seguridad" en Registro cada tanto para no perderlas si borrás los datos del navegador.

Se publica con GitHub Pages desde la rama `main`.
